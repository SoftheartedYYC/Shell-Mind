# ShellMind

[English](README.md) · [简体中文](README.zh.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Deutsch](README.de.md) · [Français](README.fr.md) · [Español](README.es.md) · [Português](README.pt.md) · [Русский](README.ru.md) · [Italiano](README.it.md)

Приложение для Android на базе Flutter: SSH-терминал и ИИ-ассистент. Подключайтесь к своим серверам по SSH, запускайте ИИ-агента, который выполняет команды на подключённых хостах (с режимами подтверждения и журналированием аудита), управляйте парком серверов и следите за состоянием кластера.

## Возможности

| Модуль | Возможности |
| --- | --- |
| **SSH-терминал** | Аутентификация по паролю / закрытому ключу ([dartssh2](https://pub.dev/packages/dartssh2)); эмуляция терминала со вспомогательной клавиатурной панелью ([xterm](https://pub.dev/packages/xterm)); автоматическое переподключение с экспоненциальной задержкой; глобальный реестр множества сеансов — сеансы продолжают работать, когда вы уходите с экрана; **6 выбираемых цветовых схем терминала** (Tokyo Night / One Dark / Dracula / Monokai / Solarized Dark / Classic) |
| **SFTP-браузер** | Просмотр каталогов с поуровневой навигацией; предпросмотр текстовых файлов; скачивание в локальное хранилище; mkdir / переименование / удаление |
| **Проброс портов** | Локальные (`ssh -L`) и удалённые (`ssh -R`) туннели; живой список туннелей с закрытием в одно касание |
| **ИИ-агент** | Выполняет команды в режиме подтверждения или в полностью автоматическом режиме; перехват опасных команд; настраиваемое максимальное количество раундов выполнения; координация нескольких серверов из одного диалога; визуальная временная шкала выполнения; полный журнал аудита команд |
| **ИИ-чат** | **Подсветка синтаксиса в блоках кода** (shell / python / json / yaml / dockerfile / sql); **управление несколькими сеансами** (новый / переключение / переименование / удаление); **поиск по истории диалогов** (заголовки + тела сообщений); экспорт в Markdown; прикрепление контекста терминала |
| **ИИ-провайдеры** | Встроенные DeepSeek / Qwen / GLM / MiMo / OpenAI (совместимые с OpenAI); пользовательские провайдеры (имя + Base URL + модели); потоковые ответы SSE; окно выбора модели с фильтрацией по поиску |
| **Управление серверами** | CRUD с группировкой и поиском; живые бейджи статуса подключения на карточках серверов; сводные карточки состояния кластера (аптайм / проверка нагрузки) с ИИ-диагностикой в один клик |
| **Импорт и экспорт** | Экспорт/импорт JSON фрагментов команд и конфигураций серверов (учётные данные никогда не экспортируются; импортированные записи получают новые ID) |
| **Уведомления** | Локальные уведомления при обрыве SSH-сеанса или завершении ИИ-задачи, пока приложение работает в фоновом режиме (настраиваемые) |
| **Безопасность и конфиденциальность** | Учётные данные шифруются через `flutter_secure_storage`; блокировка приложения по биометрии; режим скрытия IP; журнал аудита команд; экспорт диагностики ошибок |
| **Продуктивность** | Постоянная история ИИ-диалогов; фрагменты команд (двойной ввод: ИИ-чат / терминал); экспорт диалога в Markdown; прикрепление контекста терминала к ИИ-диалогам |
| **Локализация и темы** | Многоязычный интерфейс (English / 简体中文 / 日本語 / 한국어 / Deutsch / Français / Español / Português / Русский / Italiano); светлая / тёмная / по системным настройкам темы |
| **Платформы** | Android (раздельные APK по ABI); iOS (Info.plist декларирует локальную сеть и использование Face ID; разрешение на уведомления запрашивается плагином) |

## Начало работы

### Установка из Releases

1. Перейдите на страницу [Releases](https://github.com/SoftheartedYYC/Shell-Mind/releases).
2. Скачайте APK, соответствующий ABI вашего устройства, и установите его (`arm64-v8a` для современных телефонов, `armeabi-v7a` для старых 32-битных устройств, `x86_64` только для эмуляторов).
3. Приложение также проверяет обновления внутри себя (через GitHub Releases, автоматически выбирая файл, соответствующий ABI устройства).

### Сборка из исходников

Требования: Flutter 3.47+ (требует Dart SDK ^3.13.4), Java 17+, Android SDK 36.

```bash
git clone https://github.com/SoftheartedYYC/Shell-Mind.git
cd Shell-Mind
flutter pub get
flutter run
```

Сборка релизных APK (раздельно по ABI, как артефакты CI-релиза):

```bash
flutter build apk --release --split-per-abi
```

Артефакты попадают в `build/app/outputs/flutter-apk/` как `app-arm64-v8a-release.apk`, `app-armeabi-v7a-release.apk` и `app-x86_64-release.apk`. Только для локального тестирования на устройстве подойдёт и обычная `flutter build apk --release` (fat APK размером ~63 МБ для локальной установки).

> **Подпись**: для подписанной релизной сборки требуются два файла (оба исключены через `.gitignore` и никогда не коммитятся):
>
> - `android/key.properties` — скопируйте из `android/key.properties.example` и заполните реальными учётными данными;
> - `android/app/shellmind-release-key.jks` — релизное хранилище ключей (keystore).
>
> Если какой-либо из них отсутствует, сборка откатывается на конфигурацию отладочной подписи (только для локальной отладки, не для распространения). Официальные сборки проверены с JDK 17 и JDK 25.

## Релиз через CI/CD

Публикация тега `v*` (например `v1.4.1`) запускает [GitHub Actions](.github/workflows/release.yml):

1. Проверяет, что тег совпадает с версией в `pubspec.yaml` (иначе завершается ошибкой);
2. Запускает тестовый шлюз (`flutter pub get` / `flutter analyze` / `flutter test`, любая ошибка прерывает релиз);
3. Собирает подписанные релизные APK (`--split-per-abi`, имена `Shell-Mind-v{version}-{abi}.apk` для arm64-v8a / armeabi-v7a / x86_64);
4. Извлекает из [CHANGELOG.md](../CHANGELOG.md) заметки о релизе соответствующей версии на китайском, создаёт GitHub Release и автоматически загружает все APK по ABI и контрольные суммы.

В репозитории должны быть настроены два секрета в разделе **Settings → Secrets and variables → Actions** (оба представляют собой Base64 содержимого файлов):

| Секрет | Содержимое |
| --- | --- |
| `KEYSTORE_BASE64` | Base64 релизного хранилища ключей `android/app/shellmind-release-key.jks` |
| `KEY_PROPERTIES_BASE64` | Base64 файла `android/key.properties` |

Сгенерируйте с помощью PowerShell: `[Convert]::ToBase64String([IO.File]::ReadAllBytes('<path>'))`

> Если секреты отсутствуют, рабочий процесс быстро завершается ошибкой — он никогда не публикует APK с отладочной подписью.

## Отказ от ответственности

Это приложение позволяет ИИ-агенту выполнять команды на реальных серверах, а полностью автоматический режим выполняет их без подтверждения каждой команды. Перехват опасных команд — это мера предосторожности, а не гарантия. Не включайте автоматический режим без присмотра на рабочих или критически важных хостах. Используйте на свой страх и риск.
